放っておくと

切れると、発電しない・エアコンが効かない、車種によってはウォーターポンプが回らずオーバーヒートする恐れもあります。車は動かせないと思ったほうがいいです。

お店に聞くといい質問

  • 前回の交換は何年前ですか？

一般的な目安（AIの小太郎が調べたもの）：決まった交換時期はない車が多く、点検でひび割れや鳴き（キュルキュル音）を見て判断します。

見積もりを見るときのコツ

  • 数字で聞く。「そろそろ交換です」ではなく、「残り何mm？」「何年前に替えた？」と聞くと、自分で判断できます。
  • やる・やらないは、説明を聞いて自分で決める。説明がなかったら「替えないとどうなりますか？」と聞いてみてください。ただし🔴の項目、とくにブレーキとタイヤは先延ばしにしないでください。
