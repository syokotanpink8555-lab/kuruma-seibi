  • 前回はいつ替えましたか？
  • タンクの量はどうでしたか？

一般的な目安（AIの小太郎が調べたもの）：ハイブリッド車には、エンジン用とは別にモーターを動かす装置（インバーター）を冷やす冷却水があります。初回の交換は約15年・約20万kmくらいの車種もあります（車種によって違うのでメンテナンスノートで確認）。

見積もりを見るときのコツ

  • 数字で聞く。「そろそろ交換です」ではなく、「残り何mm？」「何年前に替えた？」と聞くと、自分で判断できます。
  • やる・やらないは、説明を聞いて自分で決める。説明がなかったら「替えないとどうなりますか？」と聞いてみてください。ただし🔴の項目、とくにブレーキとタイヤは先延ばしにしないでください。
