タイヤの交換時期

ブレーキ・タイヤ

別の書き方：タイヤ4本交換、スタッドレス交換

整備士の本音車検に通る溝（1.6mm）と、安全に走れる溝は別物。4mm以下か、製造から5年たったら交換。

交換の目安（整備士の基準）

🔴 今すぐ溝が4mm以下
製造から5年以上（スタッドレスも同じ）
スタッドレスの「プラットホーム」が出そう（使っているうちに出てくるおそれがあるため）
路面に当たる面や溝の中にひび割れが入ってきた
🟡 近いうちに溝が5mmくらい
⚪ 様子見でいい溝が5mmより多く、製造から5年未満で、路面に当たる面にひび割れがない（スタッドレスはプラットホームまで余裕がある）

放っておくと

雨の日に滑って事故につながります。溝が3mmあっても、ブレーキをかけたときは車の重さが前のタイヤにかかってタイヤがつぶれ、溝も押しつぶされるので、実際はほとんど溝がない状態に近くなります。

お店に聞くといい質問

  • 溝は何mm残っていますか？
  • 製造年はいつですか？

💡 横の面（サイドウォール）の細かいひびは、紫外線で表面が傷んでいるだけのことが多いです。見るのは路面に当たる面と溝の中。片べり（偏摩耗）は、たいてい空気圧の入れすぎ・足りなさが原因なので、空気圧の点検を。

一般的な目安（AIの小太郎が調べたもの）：法律で決まっている限度は溝1.6mm（スリップサインが出たら使えません）。日本自動車タイヤ協会（JATMA）は、使い始めて5年以上たったタイヤは販売店などで点検を、製造から10年たったタイヤは見た目が大丈夫でも交換をすすめています。製造時期はタイヤの横にある4桁の数字でわかります（例：「2523」なら2023年の25週目）。スタッドレスは、溝の中の「プラットホーム」が出たら（溝が半分まで減ったら）冬用としては使えません。

スタッドレスに替える前に見ること（冬用タイヤ）

整備士の目安：スタッドレスは「製造から5年たった」か「プラットホームが出そう」になったら、交換をすすめています。プラットホームが出そうな状態だと、冬のあいだ使っているうちに出てきてしまうおそれがあるためです。

下の4つはAIの小太郎が日本自動車タイヤ協会（JATMA）の資料で調べたものです（整備士のチェック済み）。

  • 溝の中の「プラットホーム」：JATMAは、雪道や凍った道では冬用タイヤの残りの溝が新品の50%以上あることを確かめるよう案内しています。溝の中に出っぱり（プラットホーム）があるタイヤでは、それが表面に出ていたら、冬用タイヤとしては使えません。スリップサイン（残り溝1.6mm）より手前で出てくる、冬用タイヤだけの目印です。
  • 製造年：横の4桁の数字で確認（見方は上の「一般的な目安」）。整備士の基準は、スタッドレスも製造から5年以上で交換（上の表）。スタッドレスは、ゴムが硬くなっていることも現場ではそこそこあるそうです（整備士）。溝が残っていて5年たっていなくても、気になるときはタイヤ販売店などで見てもらうと安心です。
  • 4本そろっているか：JATMAがまとめた都道府県の規則（2026年8月現在）では、北海道・宮城県・秋田県・兵庫県・広島県などが、雪道用タイヤを使う場合は「全車輪」に付けると書いています（チェーンを付ける方法もあります）。前だけ・後ろだけの2本では、こうした規則のすべり止めにならない場合があります。
  • 空気圧：付け替えたら、車の指定空気圧になっているか確かめます（ガソリンスタンドやタイヤ販売店でも見てもらえます。JATMA）。

積雪・凍結した道路では、冬用タイヤやチェーンなどのすべり止めが都道府県の規則で決められています（沖縄県を除く。普通車の反則金は6,000円。JATMA）。自分で見て迷ったら、タイヤ販売店やガソリンスタンド、整備工場で見てもらうのが確実です。

付ける前に見る3つは、小太郎の note「スタッドレスに替える前に、自分で見ておく3つのこと」にもまとめています。

見積もりを見るときのコツ

  • 数字で聞く。「そろそろ交換です」ではなく、「残り何mm？」「何年前に替えた？」と聞くと、自分で判断できます。
  • やる・やらないは、説明を聞いて自分で決める。説明がなかったら「替えないとどうなりますか？」と聞いてみてください。ただし🔴の項目、とくにブレーキとタイヤは先延ばしにしないでください。

タイヤをネットで買って、お店で付けてもらう方法も

交換するタイヤは、お店で買うほかに、ネットで買って取り付けだけお店に頼む方法もあります。

株式会社オートウェイ：輸入タイヤを中心に、タイヤ・ホイールを売っている通販です（広告主の案内では、海外のメーカーなどから直輸入）。オートウェイが運営する取付サービス「タイヤピット」の取付店に商品を直接送ってもらい、予約した日にそのお店で取り付けてもらえます。取り付けの工賃のほか、古いタイヤの処分料やバルブ交換料なども別にかかります。

このリンクから購入があると、このサイトに紹介料が入ります。この枠は広告で、整備士がすすめているものではありません。タイヤは、工賃や処分料も含めた総額で、ほかのお店とも比べてから決めてください。サイズは、今のタイヤの横の表示（例：195/65R15 91H。最後の数字と記号まで同じものを）や取扱説明書で確認できます。注文する前に、製造時期がいつのものかも確かめておくと安心です（このページの基準は、製造から5年で交換）。

交換時期は車種・年式・使い方で変わります。自分の車の指定は、取扱説明書とメンテナンスノートで確認してください。
