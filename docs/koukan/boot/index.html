交換の目安（整備士の基準）

🔴 今すぐ見積もりに出てきた

放っておくと

中のグリス（潤滑剤）が飛び出して、ドライブシャフトごと交換になる恐れがあります。部品代も工賃も大きく上がります。

💡 破れる前に予防で見積もりを出されることは、ほとんどありません（手間がかかって汚れる作業のため）。

一般的な目安（AIの小太郎が調べたもの）：タイヤに力を伝える軸（ドライブシャフト）の、つなぎ目を守るゴムのカバーです。破れていると車検に通りません。

見積もりを見るときのコツ

  • 数字で聞く。「そろそろ交換です」ではなく、「残り何mm？」「何年前に替えた？」と聞くと、自分で判断できます。
  • やる・やらないは、説明を聞いて自分で決める。説明がなかったら「替えないとどうなりますか？」と聞いてみてください。ただし🔴の項目、とくにブレーキとタイヤは先延ばしにしないでください。
