シートベルト警告灯が点いたら

お知らせ

見た目：赤い、シートベルトを締めた人の形（色：赤）

運転席や助手席（車種によっては後席）のシートベルトが締められていません。

どうすればいい？

  • シートベルトを締めれば消えます。助手席に重い荷物を置いていると反応することがあります。

💡 締めているのに消えない場合は、バックルのセンサーの不具合の可能性があります。

シートベルトの決まり

道路交通法第71条の3で、運転する人は自分がシートベルトを着けるだけでなく、後部座席を含む全ての座席の同乗者にも着けさせなければならないことになっています（病気などやむを得ない理由がある場合を除く）。

後部座席で着けていないと、高速道路（高速自動車国道・自動車専用道路）では、運転する人に違反点数1点が付きます。一般道でも、着ける義務があることは同じです。

6歳未満の子どもや、体格などでシートベルトをうまく着けられない子どもには、チャイルドシートを使います。

警察庁の調査（2025年）では、運転席・助手席の着用率は96%を超えていますが、後部座席は一般道で45.8%、高速道路などで79.9%にとどまっています。

後部座席こそ着けておきたい理由

警察庁によると、後部座席でシートベルトを着けていないときの致死率（死傷者のうち亡くなった人の割合）は、着けているときの高速道路で約13.9倍、一般道で約2.8倍です。

ぶつかったときに車内で全身を強く打つ、車の外に投げ出される、前の席の人にぶつかってけがをさせる、といったことが起こりえます。

シートベルトの警報（このランプと警告音）は、以前は乗用車では運転席だけが対象でした。2017年に保安基準が改正され、2020年9月以降に新しく型式の認可を受けた乗用車は、後部座席を含む全ての座席が警報の対象になりました。後部座席は、エンジンをかけたときは表示だけで、走っている途中でベルトを外すと音でも知らせます。それより前から売られている型の車は、後部座席に警報がないこともあります。

色でわかる緊急度

このランプは赤（お知らせ：状況を確認すればOKなことが多い）です。

  • 赤：すぐに安全な場所に停めて確認・相談
  • 黄・オレンジ：すぐ止まらなくてよいことが多いが、早めに点検
  • 緑・青：装置が作動中などのお知らせ（異常ではない）

「走れる」警告灯でも、運転するのが不安なときは無理に走らず、レッカーを呼ぶのも手です（レッカーという選択肢）。
