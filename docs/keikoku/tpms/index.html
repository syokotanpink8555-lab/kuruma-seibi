タイヤ空気圧警告灯が点いたら

早めに点検

見た目：黄色の、タイヤの断面（U字）の中に「！」（色：黄・オレンジ）

タイヤの空気圧が下がっています。パンクの可能性もあります。

どうすればいい？

  • 安全な場所に停めて、タイヤがつぶれていないか目で見て確認してください。
  • ガソリンスタンドなどで、運転席ドアの付近に貼ってある指定の空気圧に合わせてください。
  • 空気を入れてもすぐ下がる場合はパンクの可能性があるので修理してください。

💡 寒くなる季節は気温で空気圧が下がって点くこともあります。調整後にリセット操作が必要な車種もあります。

タイヤのトラブルは、JAFの出動理由の上位です

JAFロードサービスの2025年度（2025年4月〜2026年3月）の四輪の出動理由では、「タイヤのパンク、バースト、エアー圧不足」が高速道路で1位（44.02%）、一般道路で2位（20.55%）でした。高速道路では、2位の燃料切れ（8.62%）を大きく上回っています。

空気圧は、何もしなくても下がります

日本自動車タイヤ協会（JATMA）が2025年に行った路上のタイヤ点検では、空気圧などを実際に測った340台のうち183台（53.8%）にタイヤの整備不良がありました。項目別では、点検した車のおよそ半分（49.7%）が「空気圧不足」で、一番多い結果でした。

JATMAは、タイヤの空気は何もしなくても自然に漏れて空気圧が下がっていくため、スペアタイヤも含めて最低1か月に1度は点検するよう呼びかけています。

空気圧が足りないまま走ると、タイヤが異常に熱を持って傷み、はがれ（セパレーション）やバーストの原因になります。燃費の悪化や、タイヤの両肩が早くすり減る原因にもなります。

空気圧の合わせ方（JATMAの案内）

測るのは、走る前のタイヤが冷えているときです。車の指定空気圧（取扱説明書や、運転席ドア付近などのラベルに書いてあります）を基準に、0〜＋20kPaの範囲に合わせます。高速道路を走るときの空気圧が取扱説明書に書いてある車は、それに従います。

走ったあとはタイヤが熱を持って空気圧が上がりますが、上がった分の空気は抜かないでください。冷えると元に戻ります。

偏平タイヤ（横から見たときに、ゴムの側面の高さが低いタイヤ）は、空気が足りなくても見た目では分かりにくいので、エアゲージで測ります。バルブキャップは、泥水が入って空気が漏れるのを防ぐので、必ず付けておきます。

警告灯が点いていなくても、月1回の点検は必要です。スタッドレスに付け替える時期の確認はタイヤの交換時期のページにまとめています。

色でわかる緊急度

このランプは黄・オレンジ（早めに点検：近いうちに整備工場へ）です。

  • 赤：すぐに安全な場所に停めて確認・相談
  • 黄・オレンジ：すぐ止まらなくてよいことが多いが、早めに点検
  • 緑・青：装置が作動中などのお知らせ（異常ではない）

「走れる」警告灯でも、運転するのが不安なときは無理に走らず、レッカーを呼ぶのも手です（レッカーという選択肢）。
