お知らせ

見た目：青い、ライトから横向きにまっすぐ線が出ている形（色：青）

ヘッドライトがハイビーム（上向き）になっています。

どうすればいい？

  • 対向車や前の車がいるときはロービーム（下向き）に切り替えてください。

ハイビームとロービームの使い分け

道路交通法第52条で、夜に対向車とすれ違うときや、前の車のすぐ後ろを走るときに、相手の交通の妨げになるおそれがあれば、ライトを下向きにする・暗くするなどの操作をすることが決められています。

警察庁は、街灯が少ない暗い道で、対向車や前の車がいないときはハイビームを使うようすすめています。交通量の多い市街地ではロービームを使い、対向車が自転車のときも、確実にロービームに切り替えます。

保安基準で、ハイビームは前方100m、ロービームは前方40mの障害物を確認できる性能が求められています。警察庁によると、ハイビームなら歩行者を2倍以上遠くから見つけられます。

秋から冬の夕方は、とくに気をつけたい

警察庁の分析（2021〜2025年）では、夕方の薄暗い時間帯の死亡事故は10月〜12月に最も多くなっています。夕方から夜の死亡事故は17時台〜19時台に多く、その4割以上が車と歩行者の事故です。

ハイビームのまま対向車に気づかないと、相手をまぶしくさせてしまいます。このランプが点いていたら、まわりに車や自転車がいないか確かめてください。自動で切り替える「オートハイビーム」の車もあります（自動ブレーキ・オートクルーズ・オートハイビーム、何をしてくれる？）。

この欄は整備士のチェックを受けていません。AIの小太郎が下の公的資料と法令で調べてまとめたものです（2026年11月時点）。

色でわかる緊急度

このランプは青（お知らせ：状況を確認すればOKなことが多い）です。

  • 赤：すぐに安全な場所に停めて確認・相談
  • 黄・オレンジ：すぐ止まらなくてよいことが多いが、早めに点検
  • 緑・青：装置が作動中などのお知らせ（異常ではない）

「走れる」警告灯でも、運転するのが不安なときは無理に走らず、レッカーを呼ぶのも手です（レッカーという選択肢）。
