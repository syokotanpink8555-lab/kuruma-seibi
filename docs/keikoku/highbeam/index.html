お知らせ

見た目：青い、ライトから横向きにまっすぐ線が出ている形（色：青）

ヘッドライトがハイビーム（上向き）になっています。

どうすればいい？

  • 対向車や前の車がいるときはロービーム（下向き）に切り替えてください。

色でわかる緊急度

このランプは青（お知らせ：状況を確認すればOKなことが多い）です。

  • 赤：すぐに安全な場所に停めて確認・相談
  • 黄・オレンジ：すぐ止まらなくてよいことが多いが、早めに点検
  • 緑・青：装置が作動中などのお知らせ（異常ではない）

「走れる」警告灯でも、運転するのが不安なときは無理に走らず、レッカーを呼ぶのも手です（レッカーという選択肢）。
