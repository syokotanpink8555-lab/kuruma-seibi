オイル交換時期の計算ツール

排気量・オイル量・タイヤのサイズと、前回交換した日・走行距離を入れると、次の交換の目安を計算します。 現役の一級自動車整備士の考え方をもとに、「おすすめの時期」と「遅くともここまで」の2段階で表示します。

⚠️ 計算結果は「目安」です。
  • 計算の係数は、現役の整備士が実際の車で試しながら決めたもので、まだ試した車種は多くありません。使った人の声を聞いて見直していきます。
  • 年式・走行距離は「10年以上、または10万km超」かどうかの2段階だけで見ています。同じ車でも、乗り方やエンジンの状態で汚れ方は変わります。
  • ディーゼル車は、係数を決めた整備士の専門外です。とくに参考程度にして、取扱説明書の交換時期を優先してください。
  • 「おすすめ」で交換するのが基本です。「遅くとも」は、都合がつかなくても超えないでほしい線で、ここまで延ばしてよいという意味ではありません。
  • 取扱説明書の交換時期（距離・期間）が、このツールの「遅くとも」より短いときは、取扱説明書の時期までに交換してください（シビアコンディションの指定も含みます）。
  • 月に1回くらい、オイルレベルゲージで量を見てください。減っている・漏れている・異音がするなど、いつもと違うときは、時期に関係なくお店で点検を受けてください。走行中に油圧の警告灯（赤）がついたら、安全な場所に止めてエンジンを切り、お店やロードサービスに連絡してください。
  • この時期で交換すれば故障しない、という保証ではありません。

計算の考え方

基準は1.5Lのガソリン車（オイル3.7L・タイヤ175/65R15）で、おすすめ4,500km。そこから次の3つで早めたり遅めたりしています。

  • オイル量：オイルが多いほど、1Lあたりの負担が減って長持ちします。
  • タイヤの外径：外径が大きいほど、1km走るあいだのタイヤの回転が少なく、エンジンの回転も少なくてすみます。インチの数字ではなく、タイヤ全体の直径で考えます。
  • エンジンのタイプ：ターボ・ディーゼルは早め、ハイブリッドはエンジンが止まっている時間があるぶん長め。軽自動車は、オイルが少なく、タイヤが小さく、力がないぶん高回転で回るので早めです。
  • 車の年数・走行距離：10年以上、または10万kmを超えた車は2割早めます。

おすすめの距離は最大10,000km、遅くともの距離は最大12,000kmで止めています。期間はターボ・ディーゼルが6ヶ月、それ以外は1年です。

ツールはAIの小太郎が作り、係数は現役の整備士が決めました。

古い車は？

最近のエンジンは汚れにくく、年式の古い車や走行距離が多い車ほど汚れやすい傾向があります。このツールでは、10年以上、または10万kmを超えた車は2割早めて計算します（2割という値は、現役の整備士が決めました）。それより新しくても、抜いたオイルの汚れがひどいときは早めにしてください。

取扱説明書には「15,000km」と書いてあるけど？

国内メーカーの取扱説明書では、ターボなしのガソリン車で「15,000kmまたは1年」となっている車種も多くあります。 ただ、整備の現場から見ると15,000kmは遅すぎるというのが正直なところです。 オイルが汚れたまま走るとエンジンの中が少しずつ削れ、そのスピードが早くなってエンジンの寿命を縮めます。 逆に、取扱説明書の交換時期（距離・期間）が、このツールの「遅くとも」より短いときは、取扱説明書の時期までに交換してください（シビアコンディションの指定も含みます）。

「シビアコンディション」は気にしたほうがいい？

取扱説明書には、短い距離の運転や渋滞が多い使い方（シビアコンディション）だと交換時期を短くするよう書かれています。 このツールでは「街乗り・ちょい乗りが多い」を選ぶと、少し早めに計算します。 このツールの距離は、取扱説明書のふつうの時期より短めにしてあります。そのうえで期間（1年、ターボ・ディーゼルは6ヶ月）を守っていれば、整備士の目からはそこまで心配しなくてよい、という考えです。 ただ、取扱説明書でシビアコンディションの時期が決まっている車、とくに新車保証の期間中は、取扱説明書どおりにするのが確実です（保証の条件になっていることがあります）。

自分の車に合った時期を知るには

いちばん確かなのは、交換のときに抜いたオイルの汚れ具合をお店の人に聞いてみることです。 汚れがひどければ次は早めに、きれいなら今のペースで大丈夫。何回か続けると、自分の乗り方と車に合った交換時期がわかってきます。

オイルエレメント（フィルター）は？

オイル交換2回に1回の交換が一般的な目安です。ただし、抜いたオイルにライトを当てても全く透けないほど汚れているときは、回数に関係なく交換したほうがいいです。

あまり走らないなら交換しなくていい？

エンジンオイルは走らなくても時間とともに劣化します。距離が少なくても、1年（ターボ・ディーゼルは6ヶ月）たったら交換しましょう。

使ってみた感想を教えてください

この計算は、まだ育てている途中です。使ってみて「うちの車だと早すぎる・遅すぎる」と感じたら、小太郎の note の記事「オイル交換の目安ツールを作りました（感想募集）」のコメント欄で教えてください。

あると助かる情報：エンジンのタイプ・排気量・タイヤサイズ・だいたいの年式、計算結果、交換したときのオイルの汚れ具合（お店の人の一言でOK）。コメントするには note のアカウントが必要で、コメントは公開されます。ナンバー・お名前・お店の名前など、個人やお店がわかることは書かないでください。
