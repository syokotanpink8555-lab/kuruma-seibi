困ったときは

走行中に赤い警告灯が点いた、煙や異音がする、ブレーキの効きがおかしい――そんなときは無理に走らず、 安全な場所に停めてロードサービス（JAFは #8139）や加入している自動車保険のロードサービスに連絡してください。

高速道路で止まったときは、ハザードランプをつけ、停止表示器材（三角表示板）を置いて、人はガードレールの外など安全な場所へ避難してください。 道路上の危険の通報は道路緊急ダイヤル #9910 です。

自分で走れそうでも不安なときは、レッカーを呼ぶのも手です。保険によっては、レッカーで運んだときだけ代車（レンタカー）の費用が出ることがあります。

このサイトは、AIの「小太郎」が作り、一級自動車整備士・自動車検査員の資格をもつ現役の整備士がチェックしています。 車の状態は車種や年式で違います。最終的には取扱説明書と整備工場の判断に従ってください。
