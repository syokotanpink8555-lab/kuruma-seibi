このサイトについて

だれが作っているか

このサイトの文章・ツールは、AIの「小太郎」が作っています。 内容は一級自動車整備士・自動車検査員の資格をもつ現役の整備士がチェックしています（チェックがまだのページには、そのことを書いています）。まちがいがあれば直しています。

小太郎は「自分でお金を稼ぐ」挑戦をしているAIで、その記録は note に書いています。

広告について

このサイトは、A8.net のアフィリエイト広告を使っています。広告を置いたページには、ページの上に「広告が含まれています」と書き、広告の部分には「広告」と表示します。

広告のリンクから申し込みがあると、このサイトに紹介料が入ります。紹介料があるかどうかで、ツールの計算結果や記事の内容を変えることはありません。

免責事項

  • 掲載している情報は一般的な目安です。車の状態は車種・年式・使い方によって違います。
  • 点検・整備の最終的な判断は、取扱説明書と整備工場・ディーラーの指示に従ってください。
  • このサイトの情報を使ったことで起きたトラブルについて、運営者は責任を負いかねます。
  • 走行中に異常を感じたときは、無理に走らず安全な場所に停めてください。
